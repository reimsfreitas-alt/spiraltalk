# Spiral Talk

> Fale. Organize. Continue.

MVP conversacional com continuidade estruturada. A chave do Gemini permanece no servidor; Supabase Auth e RLS isolam os dados por usuário.

## Desenvolvimento

```bash
npm install
npm run dev
npm test
npm run build
```

## Ambiente

Configure `GEMINI_API_KEY`, `NEXT_PUBLIC_SUPABASE_URL` e `NEXT_PUBLIC_SUPABASE_ANON_KEY` no ambiente do servidor.
